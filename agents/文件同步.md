# agents/文件同步（本项目发布 / 版本 / 双远端）

> 触发时机：发布、版本号变更、Release 操作、dmg 打包时读取本文件。
> **通用平台知识（GitHub/Gitee API 坑、凭据约定）在全局库**：`~/.config/opencode/agents/分发平台同步.md`，涉及 release API 调用时一并读取。

## 一键发布

```bash
bash release.sh        # 仓库根
```

覆盖全流程（脚本内自校验）：
1. 双架构构建（aarch64 + x86_64，版本号取自 `src-tauri/tauri.conf.json`）
2. 推 main + tags 到 origin（GitHub）与 gitee 双远端
3. 双平台 Release 创建/复用 + 资产幂等上传
4. 从 Gitee 实测下载 aarch64 dmg 校验 sha256

**版本号变更**需同步三处：`package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml`。

## 本项目凭据

- 存放：`~/.config/release-tokens/desktop-translation.env`
  - `GH_TOKEN`（也已 `gh auth login` 进 keyring，`gh` 直接可用）
  - `GITEE_TOKEN`
- 文件不存在时提示用户自行生成并写入（gitee 私人令牌 / github fine-grained token）。

## 本项目 Release 地址

- GitHub: https://github.com/restyhap/desktop-02-translation （origin）
- Gitee: https://gitee.com/restyhap/desktop-02-translation （gitee；仓库须保持公开，私有可能导致附件 403）
- 资产命名：`DesktopTranslation_{版本}_{aarch64|x64}.dmg`

## 数据无损原则（升级/替换应用时）

用户数据全部在 app 包外，替换 `/Applications` 里的 .app 不丢任何数据：
- SQLite（设置/历史/词库）、`settings.json`：`~/Library/Application Support/<bundle-id>/`
- LaunchAgent 登录项：`~/Library/LaunchAgents/Desktop Translation.plist`（路径不变即持续生效）
