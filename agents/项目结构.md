# agents/项目结构（代码地图 / 常用命令 / 历史坑）

> 触发时机：首次进场做全局探索，或改动设置/窗口/词典相关代码时读取本文件。

## 代码地图

```
src/                          ← React 19 前端（Tailwind 4）
  App.tsx                     设置持有与全量落库（saveSettings 深合并 DEFAULT_SETTINGS）
  TranslatePopup.tsx          划词弹窗业务层
  toast.tsx / translate.tsx   临时小窗入口（运行时 show/hide）
  pages/{SettingsPanel,DictionaryPanel,HistoryPanel,VocabularyPanel}.tsx
  lib/{i18n,ttsCache,ttsPreview,pcmPlayer,dictPhonetic,dictSounds,audioUrl,ttsCache}.ts
  types/{settings,translation}.ts    ← DEFAULT_SETTINGS 与 Rust 侧默认值须同步（如 historyRetentionDays=30）
  storage/index.ts            invoke 命令封装层（前端唯一后端入口）

src-tauri/
  src/lib.rs                  Builder 装配（插件注册顺序敏感，见下）
  src/app/{config.rs          shortcuts/general 配置（shortcut 配置在 SQLite app_settings 表）
           keyboard_hook.rs   hook 子进程控制/事件分发}
  src/commands/{windows,shortcuts,settings,engines,translation,history,vocabulary,dictionary,tts}.rs
  src/bin/keyboard_hook.rs    rdev 全局按键监听子进程
  src/bin/dictbuild.rs        词典构建工具
  src/{db,history_store,settings_store,vocabulary_store,dict,keys,translation}.rs
```

## 常用命令

| 用途 | 命令 |
|---|---|
| 类型检查 | `pnpm typecheck` |
| Rust 检查 | `cargo check`（双架构另加 `--target x86_64-apple-darwin`） |
| Rust lint | `cargo clippy --all-targets -- -D warnings` |
| 单测 | `pnpm test` / `test:rust` |
| 词典构建 | `pnpm build:dictbuild` |
| 发布 | `bash release.sh`（详见 agents/文件同步.md） |

## 历史坑（改动前先看）

- **window-state denylist**：`translate`/`toast` 必须在 denylist——否则插件按上次 visible:true 恢复，启动即现 toast 且永不自动隐藏
- **插件注册顺序**：autostart/window-state/denylist 配置都在 lib.rs Builder 里原地注释有说明，改动前通读
- **i18n**：九语 UI_LOCALES（src/lib/i18n.ts：zh/en/de/fr/es/it/pt/ru/ko），新增 key 必须九语齐备
- **historyRetentionDays**：Rust 侧 history_retention_days() 默认 30 与前端 DEFAULT_SETTINGS 保持同值
- **`scripts/` gitignore**：整目录是构建产物区；需提交的脚本放仓库根（如 release.sh）/ agents/
- **开发日志**：写 `/Users/resty/03-repository/_inbox/YYYY/MM/DD/`（索引表 + 倒序内容格式）
