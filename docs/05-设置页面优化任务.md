# 设置页面优化任务清单

> 本文档记录设置页面的问题分析与优化任务。

---

## 问题分析

### 发现的问题

| # | 问题类型 | 问题描述 | 影响 | 状态 |
|---|----------|----------|------|------|
| 1 | **数据流** | 设置未持久化到 SQLite，仅使用 mock 数据 | 重启后设置丢失 | ✅ 已修复 |
| 2 | **API Key** | API Key 未连接到 `add_api_key_cmd` 命令 | Key 无法保存到数据库 | ✅ 已修复 |
| 3 | **保存按钮** | "保存设置"按钮无实际功能 | 用户无法保存修改 | ✅ 已修复 |
| 4 | **加载状态** | 初始化时未显示 loading | 用户体验差 | ✅ 已修复 |
| 5 | **错误处理** | 无错误提示机制 | 操作失败无反馈 | ✅ 已修复 |
| 6 | **AI 模型** | LLM 区域与实际翻译引擎混淆 | 功能定位不清 | ✅ 已移除 |
| 7 | **词典目录** | 使用 `as any` 类型转换 | 类型不安全 | ✅ 已修复 |
| 8 | **导航激活** | 滚动监听可能不精确 | 导航高亮不准确 | ✅ 已优化 |
