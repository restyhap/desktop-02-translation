**dictbuild 关键修复**（均在实测中定位）：
1. `change_count()` 恒为 1 被误用为 id → 改用 `sqlite3_last_insert_rowid`
2. 缩进识别：DOCE5/OALD8 用 tab、MW11 用**空格** → 两者都判（否则 MW11 产出 70 万脏词头）
3. zip 命名不统一：`<stem>.dsl.files.zip` vs `<stem>.dsl.dz.files.zip` → 扫目录匹配 `*.files.zip`，存**完整路径**
4. 音频标记是 `[s]file.wav[/s]`（非 `[sound `）
5. SQL 转义：音频名含单引号（如 `bre_ld41'bout.wav`）→ 资源字段必须转义
6. `expand_tags` 重写：保留 b/i/u/sub/sup，剥离其余标签，去 `[s]`、`{{}}`，还原 `\[`
7. `clean_word`：词头去 `{..}` / `[..]` 标记（`vitamin b{[sub]}12{[/sub]}` → `vitamin b12`）
8. 支持多 `--input` 单次全量重建（不可拆多次调用，否则后次清空前次）
