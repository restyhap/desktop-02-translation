# 词典查找功能 — 完整实现方案

## 概述

将 GoldenDict 词典（DSL 格式）转换为 SQLite 数据库，在 Tauri 应用中实现**子串模糊搜索 + 词条展示（图片/翻译/语音）**。

---

## 数据流总图

```
.dsl.dz（dictzip压缩的DSL文本）
    │
    ▼ [一次性构建，Rust CLI]
┌─────────────────────────────────────────────┐
│  dictionaries.db (SQLite)                     │
│  ├── dictionaries 表（词典元信息）            │
│  ├── entries_data 表（词条：word + definition）│
│  ├── entries_fts 表（FTS5，用于前缀搜索）     │
│  └── resources 表（图片/语音引用 → zip 偏移） │
└─────────────────────────────────────────────┘
    │
    ▼ [程序启动，Tauri Rust 后端]
┌─────────────────────────────────────────────┐
│  rusqlite 连接 → mmap 索引                   │
│  search_cmd(text) → LIKE '%text%' 候选词     │
│  suggest_cmd(prefix) → FTS5 前缀候选词       │
│  load_resource_cmd(filename, zip) → Vec<u8>  │
└─────────────────────────────────────────────┘
    │
    ▼ [前端 RN]
┌─────────────────────────────────────────────┐
│  输入框 → 下拉候选词 → 选中 → 展示图片/翻译/语音 │
└─────────────────────────────────────────────┘
```

## 一、SQLite 数据库 Schema

### 表 1：dictionaries（词典元信息）

```sql
CREATE TABLE dictionaries (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    name          TEXT NOT NULL,        -- "Longman DOCE5"
    dict_dir      TEXT NOT NULL,        -- "/path/to/En-En_Longman_DOCE5"
    lang_from     TEXT NOT NULL DEFAULT 'en',
    lang_to       TEXT,                  -- NULL = 英英
    entry_count   INTEGER,              -- 62964
    dz_path       TEXT NOT NULL         -- "En-En-Longman_DOCE5.dsl.dz"
);
```

### 表 2：entries_data（词条正文）

```sql
CREATE TABLE entries_data (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    dictionary_id INTEGER NOT NULL REFERENCES dictionaries(id),
    word          TEXT NOT NULL,        -- 原始词头（小写，搜索用）
    word_raw      TEXT NOT NULL,        -- 原始词头（保留大小写，显示用）
    definition    TEXT NOT NULL,        -- 翻译/释义（DSL标记已展开为HTML）
    body_raw      TEXT,                  -- 原始DSL文本（可选，需要时保留）
    audio_ref     TEXT,                  -- 关联的 .wav 文件名（如有）
    FOREIGN KEY (dictionary_id) REFERENCES dictionaries(id)
);

-- 普通索引（用于 LIKE 子串搜索）
CREATE INDEX idx_entries_word ON entries_data(word);
```

### 表 3：entries_fts（FTS5 虚拟表，前缀搜索）

```sql
CREATE VIRTUAL TABLE entries_fts USING fts5(
    word,           -- 搜索词
    content='entries_data',  -- 列存储引用
    content_rowid='id'
);
```

### 表 4：resources（图片/语音引用）

```sql
CREATE TABLE resources (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    entry_id    INTEGER NOT NULL REFERENCES entries_data(id),
    kind        TEXT NOT NULL,           -- 'image' / 'audio'
    filename    TEXT NOT NULL,           -- "abe_-central1004a.wav"
    zip_path    TEXT NOT NULL,           -- 词典目录路径（含 zip 文件）
    zip_file    TEXT NOT NULL,           -- "En-En-Longman_DOCE5.dsl.files.zip"
    zip_offset  INTEGER,                  -- 偏移（可选，zip 不需要）
    zip_size    INTEGER,
    FOREIGN KEY (entry_id) REFERENCES entries_data(id)
);
```

### 搜索策略（关键决策）

| 搜索类型 | SQL | 说明 |
|---------|-----|------|
| **子串搜索（CONTAINS）** | `SELECT word FROM entries_data WHERE word LIKE '%an%' LIMIT 50` | 输入 an → tan/angle/angry 都显示。LIKE '%an%' 走全表扫描，250K 行 ≈ 几 ms，下拉场景够用 |
| **前缀搜索** | `SELECT word FROM entries_fts WHERE entries_fts MATCH 'an*' LIMIT 20` | 输入 an → angle/angry 显示。FTS5 更快 |
| **精确查词** | `SELECT * FROM entries_data WHERE word = ?` | 二分或直接等值查询 |

## 二、Rust 构建工具（dictbuild）

### crate 依赖

```toml
[dependencies]
flate2 = "1"          # gzip 解压 .dsl.dz
rusqlite = { version = "1", features = ["bundled", "fts5"] }
walkdir = "2"         # 遍历词典目录
```

### 构建流程

```
1. 遍历 /Users/resty/01-build/goldendict_dictionary/ 每个子目录
   ├── 找到 *.dsl.dz → 解压 → UTF-16LE 解码 → 解析词条
   └── 找到 *.bgl → 跳过（BGL 先不管）

2. 解析 DSL 文本（线性扫描）
   ├── 行以 `$<num> <word>` 开头 → 新词条，记录 word_raw
   ├── 后续缩进行 → 释义正文（累计 body）
   ├── 遇到空行 → 词条结束，写入 entries_data
   └── 解析 body 中的 [sound x.wav] / [img y.jpg] → 插入 resources

3. DSL 标记展开（构建时预处理）
   ├── `[m0]` / `[m1]` 等标记 → 丢弃（仅排版用）
   ├── `[b]text[/b]` → `<b>text</b>`
   ├── `[i]text[/i]` → `<i>text</i>`
   └── 其他标记 → 保留标签或丢弃

4. 批量插入 SQLite
   ├── INSERT INTO dictionaries (...)
   ├── INSERT INTO entries_data (...)  — 批量 INSERT
   ├── INSERT INTO entries_fts (...)  — FTS5 自动索引
   └── INSERT INTO resources (...)

5. 输出 dictionaries.db
```

### 关键实现细节

**UTF-16LE 解码**：`.dsl.dz` 解压后是 UTF-16LE 文本（含 BOM `\xff\xfe`）
```rust
// flate2 解压后，按 \x00 分割或用 from_utf16
let utf16: Vec<u16> = bytes.chunks_exact(2).map(|c| u16::from_le_bytes([c[0], c[1]])).collect();
let text = String::from_utf16_lossy(&utf16);
```

**词条解析**：DSL 文本中词条边界
```
$100 a throw
[语法标记]
释义内容...

$101 a threw
...
```
- 正则：`^\$\d+\s+(.+)$` 匹配词头行
- 词头后的缩进行（以 tab/空格开头）是释义
- 空行分隔词条

**DSL 标记展开**：简单状态机
- `[m0]` 到 `[/m0]` 之间的标记 → 丢弃（排版标记）
- `[b]...[/b]` → `<b>...</b>`
- `[i]...[/i]` → `<i>...</i>`
- 其他标记 → 丢弃或保留原始文本

### TranslationInput.tsx 改造

```tsx
interface TranslationInputProps {
  onDictionaryLookup?: (word: string) => void;  // 新增回调
}

export function TranslationInput({ onDictionaryLookup }: TranslationInputProps) {
  const [text, setText] = useState("");
  const [suggestions, setSuggestions] = useState<SearchResult[]>([]);
  const [showDropdown, setShowDropdown] = useState(false);
  
  // 输入时调用 suggest（防抖 150ms）
  const handleInput = async (query: string) => {
    setText(query);
    if (query.length >= 2) {
      const results = await invoke('suggest', { prefix: query });
      setSuggestions(results);
      setShowDropdown(true);
    } else {
      setShowDropdown(false);
    }
  };
  
  // 选中候选词
  const selectWord = (word: string) => {
    setText(word);
    setShowDropdown(false);
    onDictionaryLookup?.(word);
  };
  
  return (
    <div className="relative">
      <input value={text} onChange={...} onInput={handleInput} />
      {showDropdown && (
        <div className="absolute z-10 bg-white border rounded shadow-lg max-h-60 overflow-y-auto">
          {suggestions.map(s => (
            <div key={s.word} onClick={() => selectWord(s.word)}>
              {s.word}
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

### DictionaryDisplay.tsx 新增

```tsx
interface DictionaryDisplayProps {
  entry: DictionaryEntry | null;
  dictDir: string;
}

export function DictionaryDisplay({ entry, dictDir }: DictionaryDisplayProps) {
  if (!entry) return <div>输入单词查看释义</div>;
  
  return (
    <div className="flex flex-col gap-4 p-4">
      {/* 图片 */}
      {entry.images?.map(img => (
        <img key={img} src={`tauri://localhost/load_resource?file=${img}&zip=${zipFile}`} />
      ))}
      
      {/* 翻译 */}
      <div dangerouslySetInnerHTML={{ __html: entry.definition }} />
      
      {/* 语音 */}
      {entry.audio_ref && (
        <audio controls src={`tauri://localhost/load_resource?file=${entry.audio_ref}&zip=${zipFile}`} />
      )}
    </div>
  );
}
```
