# 桌面翻译软件 - 需求分析

## 1. 项目概述

### 1.1 产品定位
一款跨平台桌面翻译软件，结合 GoldenDict 的词典查询能力与 uTools 翻译工具的便捷交互体验。

**翻译策略**：
- **在线翻译**：调用云端 API（Google、DeepL、百度、有道等）
- **离线翻译**：使用 MDX 词典（GoldenDict 格式）

### 1.2 目标用户
- 需要频繁阅读外文文档的开发者、研究人员
- 注重隐私、需要离线翻译的用户
- 需要专业词典查询的翻译工作者

### 1.3 技术栈
- **框架**: Tauri 2.x (Rust + Web)
- **前端**: React + TypeScript
- **在线翻译**: 云端 API（Google、DeepL、百度、有道等）
- **离线翻译**: MDX 词典（GoldenDict 格式）
- **词典格式**: MDX, StarDict, DSL 等

## 3. 翻译引擎

### 3.1 云端 API 翻译（主要方式）

**支持的 API**：

| API | 语言数 | 特点 | 配置项 |
|-----|--------|------|--------|
| Google Translate | 130+ | 覆盖广、免费额度 | API Key |
| DeepL | 30+ | 翻译质量高 | API Key |
| 百度翻译 | 200+ | 中文支持好 | App ID + Key |
| 有道翻译 | 112+ | 国内稳定 | App ID + Key |
| 腾讯翻译 | 214+ | 企业级 | Secret ID + Key |
| 阿里翻译 | 214+ | 阿里云生态 | Access Key + Secret |

**配置示例**：
```yaml
translation:
  engines:
    - name: "DeepL"
      type: "deepl"
      api_key: "your-api-key"
      priority: 1
    - name: "Google"
      type: "google"
      api_key: "your-api-key"
      priority: 2
  fallback:
    - type: "dictionary"  # 降级到本地词典
```

**引擎切换逻辑**：
1. 优先使用用户指定的引擎
2. 请求失败时自动切换到下一优先级
3. 无网络时降级到本地词典
4. 所有引擎不可用时显示错误提示

### 3.2 本地词典（离线兜底）

**词典格式**：

| 格式 | 扩展名 | 来源 | 说明 |
|------|--------|------|------|
| MDict | .mdx/.mdd | 最常用 | 支持富文本、图片 |
| StarDict | .ifo/.dict/.idx | 开源 | 传统格式 |
| DSL | .dsl(.dz) | ABBYY Lingvo | 专业词典 |
| XDXF | .xdxf(.dz) | 开放标准 | 结构化词典 |
| Zim | .zim | Wikipedia 离线 | 百科类 |
| Slob | .slob | Aard 2 | 轻量格式 |

**词典管理**：
- 拖拽导入词典文件
- 按语言/类型分组
- 启用/禁用单个词典
- 词典优先级排序
- 词频排序显示

**离线场景**：
- 断网时自动切换到词典查询
- 词典查询速度极快（本地索引）
- 支持模糊搜索和词形变化

## 5. 交互设计

### 5.1 核心功能：快捷键唤醒翻译

**这是软件的核心体验**：用户在任意应用中选中文本，按下快捷键，立即弹出翻译结果。

#### 唤醒流程

```
┌─────────────────────────────────────────────────────────────┐
│                    用户操作流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. 在任意应用（浏览器、IDE、PDF 阅读器）中选中文本           │
│  2. 按下快捷键（如 Cmd/Ctrl + Shift + T）                   │
│  3. 翻译弹窗立即出现在鼠标位置                              │
│  4. 显示翻译结果                                            │
│  5. 点击其他区域或按 Esc 关闭弹窗                           │
└─────────────────────────────────────────────────────────────┘
```

#### 技术实现（Tauri）

```rust
// Rust 后端：注册全局快捷键
use tauri::GlobalShortcutManager;

// 在 app 启动时注册
app.global_shortcut_manager()
   .register("CmdOrCtrl+Shift+T", move |event| {
       // 1. 获取剪贴板内容或当前选中文本
       // 2. 发送到前端渲染翻译弹窗
       // 3. 显示弹窗在鼠标位置
   })?;
```

#### 唤醒方式

| 方式 | 触发条件 | 说明 |
|------|----------|------|
| **全局快捷键** | `Cmd/Ctrl + Shift + T` | 最常用，任意位置唤醒 |
| **划词自动** | 鼠标选中文本后停顿 | 可选功能，自动弹窗 |
| **剪贴板监听** | 复制文本后触发 | 可选功能，复制即译 |
| **系统托盘** | 点击托盘图标 | 打开主窗口 |

#### 弹窗行为

| 行为 | 配置项 | 默认值 |
|------|--------|--------|
| 弹窗位置 | 鼠标位置 / 屏幕中心 | 鼠标位置 |
| 失焦隐藏 | 失焦后自动关闭 | 开启 |
| 置顶显示 | 弹窗始终在最前 | 关闭 |
| 自动关闭 | 翻译完成后自动关闭 | 关闭 |
| 显示时长 | 弹窗显示时间 | 无限（手动关闭） |

**关键 Rust 代码示例**：

```rust
// 注册全局快捷键
use tauri::{GlobalShortcutManager, Manager};

#[tauri::command]
fn setup_shortcuts(app: AppHandle) -> Result<(), String> {
    let mut shortcut_manager = app.global_shortcut_manager();
    
    // 注册划词翻译快捷键
    shortcut_manager
        .register("CmdOrCtrl+Shift+T", move |_event| {
            // 获取剪贴板内容
            // 发送事件到前端
            // 前端显示翻译弹窗
        })
        .map_err(|e| e.to_string())?;
    
    Ok(())
}

// 创建翻译弹窗
#[tauri::command]
fn show_translate_window(app: AppHandle, text: String, x: f64, y: f64) {
    if let Some(window) = app.get_window("translate") {
        // 更新位置和内容
        window.set_position(tauri::Position::Physical(tauri::PhysicalPosition {
            x: x as i32,
            y: y as i32,
        }));
        window.show();
        window.set_focus();
    }
}
```

**关键 React 代码示例**：

```tsx
// 翻译弹窗组件
import { listen } from '@tauri-apps/api/event';

function TranslatePopup() {
  const [result, setResult] = useState('');
  const [position, setPosition] = useState({ x: 0, y: 0 });
  const [visible, setVisible] = useState(false);

  useEffect(() => {
    // 监听 Rust 发送的翻译事件
    const unlisten = listen<{ text: string; x: number; y: number }>(
      'show-translate',
      (event) => {
        setPosition({ x: event.payload.x, y: event.payload.y });
        setVisible(true);
        // 调用翻译 API
        translate(event.payload.text).then(setResult);
      }
    );

    return () => {
      unlisten.then((fn) => fn());
    };
  }, []);

  if (!visible) return null;

  return (
    <div 
      className="translate-popup"
      style={{ left: position.x, top: position.y }}
    >
      <div className="result">{result}</div>
      <button onClick={() => setVisible(false)}>关闭</button>
    </div>
  );
}
```
