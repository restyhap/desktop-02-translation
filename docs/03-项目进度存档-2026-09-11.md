## Critical Bugs（运行时崩溃）

### Bug 1：`get_translations_cmd` 未注册
- **位置**：`lib.rs:378-395`
- **现象**：HistoryList 调用 `invoke("get_translations_cmd")` → 命令不存在
- **影响**：历史记录页面完全不可用
- **修复**：在 `invoke_handler!` 中添加 `get_translations_cmd`

### Bug 2：Vocabulary 命令未注册
- **位置**：`storage/index.ts:68,73`
- **现象**：`get_vocabulary_groups_cmd` / `get_vocabulary_words_cmd` 未注册
- **影响**：词组面板完全不可用
- **修复**：注册相关命令

### Bug 3：Google Translate serde 字段名不匹配
- **位置**：`translation.rs:26`
- **现象**：API 返回 `translatedText`，代码用 `translated_text`
- **影响**：Google 翻译 100% 报错
- **修复**：添加 `#[serde(rename = "translatedText")]`

### Bug 4：`get_schema_version` 类型读取错误
- **位置**：`db.rs:134`
- **现象**：INTEGER 列用 `read::<String>` 读取
- **影响**：`needs_migration` 总是返回 true
- **修复**：改为 `read::<i64>`

### Bug 5：ShortcutRecorder 事件监听泄漏
- **位置**：`ShortcutRecorder.tsx:83-98`
- **现象**：匿名函数 keyup listener 无法移除
- **影响**：内存泄漏
- **修复**：提取为命名引用

### Bug 6：TranslatePopup 事件监听泄漏
- **位置**：`TranslatePopup.tsx:128-153`
- **现象**：`win.listen` 未在 effect cleanup 中 unlisten
- **影响**：引擎切换多次后重复触发翻译
- **修复**：在 effect return 中调用 unlisten

## 技术决策（更新）

### 1. 数据库选型
- **选择**：原生 SQLite（非 Prisma ORM）
- **理由**：Tauri 原生支持、零依赖、单文件易迁移
- **状态**：✅ 已实现（`db.rs`）

### 2. API Key 存储策略
| 版本 | 方案 | 状态 |
|------|------|------|
| **v0.1** | 明文 SQLite | ✅ 已实现（`keys.rs`） |
| **v0.2** | 加密存储 | ❌ 待实现 |

### 3. 快捷键方案
- **设计原则**："首击零拦截 + 时间窗口状态机"
- **技术实现**：`rdev` 全局键盘监听
- **状态**：✅ 已实现（支持配置目标键），但不支持修饰键组合

### 4. 架构演进路径
```
v0.1 (当前) → v0.2 → v0.3 → v0.4 → v1.0
    ↓           ↓       ↓       ↓       ↓
  明文存储   加密存储  词典加载  截图OCR  正式发布
  API接入    迁移工具  词典管理  术语表    性能优化
  基础功能   功能完善  功能增强  多平台测试
```
